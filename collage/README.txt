COLLAGE FOLDER
Drop your images here (png / jpg / jpeg / webp / gif*).

Two ways the site finds them:
1. Name them 1.png, 2.jpg, 3.png ... (up to 60) — detected automatically.
2. Name them anything, then double-click update-manifest.command in the
   site root. (First time macOS may block it: right-click -> Open.)

* gifs display as stills — everything is re-rendered low-res on purpose.
